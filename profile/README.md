# EDOS Business

Business operations account for EDOS (Enterprise DevOps Solutions LLC), Boise, Idaho.

EDOS builds tools for teams that work with AI coding agents:

- **[Ork Meter](https://orkmeter.com)** tracks your Claude Code and Codex usage in one live dashboard. Ork Meter Plus adds a plugin that trims noisy tool output before the agent reads it. [Install](https://orkmeter.com/install)
- **[Orkestera](https://orkestera.com)** gives work a goal: follow its progress, review the result, and inspect the usage it records.
